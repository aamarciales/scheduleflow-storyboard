# ScheduleFlow plugin storyboard

Interactive UI walkthrough of the ScheduleFlow Webflow Designer Extension.

Open **[the GitHub Pages site](https://aamarciales.github.io/scheduleflow-storyboard/)** to review every screen at the real Webflow `comfortable` size (320 × 460). Panels are clickable: walk Activity → What → When → Review without installing the App.

This repo contains only static HTML, CSS, and JavaScript. It does not call Webflow or the production Worker.
